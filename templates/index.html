About this project

{{ app_name }} is a small web application that reports the health of the server it runs on. It reads CPU, memory, disk, load and uptime from the operating system, shows them on a live dashboard, and offers the same data through JSON, health, readiness and Prometheus endpoints.

I built it as a practice project to learn how one application moves through the whole DevOps toolchain: Git, CI, containers, infrastructure as code, cloud deployment and monitoring. Each endpoint exists because a specific DevOps tool will use it later.

Current status: the application, dashboard and unit tests are complete. Docker, CI/CD, Terraform and AWS, Kubernetes and monitoring are planned next.

How it was built

  1. Flask skeleton. Created the app and the routes for the dashboard and API.
  2. Metric collection. A collect_status() function uses psutil to read CPU, memory, disk and load.
  3. Health logic. Thresholds come from environment variables. A metric above its limit is a warning, and the overall state becomes "degraded".
  4. Probe endpoints. /health and /ready for load balancers and Kubernetes, /metrics in Prometheus text format.
  5. Dashboard. JavaScript fetches /api/status every 3 seconds and redraws the rings and chart.
  6. Tests. Unit tests check every endpoint and the threshold logic, so a CI pipeline can run them.
